# LP Photography

A luxury digital stationery landing page and portfolio for **LP Photography** ("Making Every Occasion Special"), specializing in **Wedding and Traditional Photography**, built with **React 19**, **Vite**, and **Tailwind CSS**.

## Features

- **Luxury Digital Stationery Design**: Pressed cotton texture layering, double blind-debossed inset hairline frames, subtle corner accents (`✦`), micro-border frames, and warm botanical color tokens (`Forest Green`, `Butter Cream`, `Warm Beige`, `Champagne Gold`).
- **Brand Monogram & Typography**: Official LP Photography SVG logo with globally configured Inter typography.
- **Service Curation**: Minimal single-column repertoire showcasing 8 wedding and traditional photography services (Wedding Events, Destination Weddings, Baby Showers, Name Ceremonies, Puberty Ceremonies, Housewarming, Corporate & College Events).
- **Curated Photography Portfolio**: High-resolution gallery collage of all 9 original uncompressed photographs framed with fine art passe-partout mats and archival plate badges.
- **Direct Engagement CTAs**: WhatsApp direct-chat CTA and Instagram portal.
- **Optimized Performance**: Fast loading with modern Tailwind CSS compilation and responsive asset delivery.

## Development

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
